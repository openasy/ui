# 0008. Open source: Apache-2.0, developed in public

- **Status:** Accepted
- **Area:** Project

## Context

Security tools must be inspectable, and nobody should be locked in.

## Decision

- All code is published under Apache-2.0, including the UI library, products and this documentation.
- Issues, roadmaps and decisions (these ADRs) are public. Changes go through pull requests.
- Each repository has a SECURITY.md with a private disclosure address and response times.

## Consequences

- No closed "enterprise edition" features and no licence keys. The code is the same for everyone.
- The project is funded by support plans (Standard and Enterprise): response times, help with installs and upgrades, 24/7 cover. Paying never unlocks code.
