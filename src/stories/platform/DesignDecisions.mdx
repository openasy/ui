# Design decisions

The decisions every OpenAsy product follows are on the site: [openasy.github.io/principles](https://openasy.github.io/principles), with each record's decision and implementation status.

This page shows the decisions about how this library is built. The source of truth is `docs/decisions/` in this repository; change a decision with a pull request.

| #    | Decision                              | Area        | Decision status | Implementation |
| ---- | ------------------------------------- | ----------- | --------------- | -------------- |
| 0001 | Design tokens are CSS variables       | Styling     | Accepted        | Implemented    |
| 0002 | How the theme is chosen and applied   | Behaviour   | Accepted        | Implemented    |
| 0003 | Every story is an accessibility test  | Quality     | Accepted        | Implemented    |
| 0004 | Distributed as a GitHub release asset | Engineering | Accepted        | Implemented    |
